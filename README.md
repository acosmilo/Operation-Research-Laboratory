# Operation-a-Laboratory
This repo is a help for students on Industrial Engineer to understand about OR basic models. Since Linear Programing until More complicated problems. I used CLAUDE to make the code. I use the theory concept of Hiller and Taha books about OR. I make the activities of labs with a new problems.

# Index
- LAB_OR_1 : Intro: Graph Method, Modelo Expandido 
- LAB_OR_2 : Intro: Solver Excel, Modelo Generalizado, Sensibilidad (Deber 1 muchos ejercicios graficas y Excel)
- LAB_OR_3 : Intro: Python Codigo Expandido y Generalizado, Sensibilidad (Deber 2 muchos ejercicios graficas, Excel y python, PRUEBA)
- LAB_OR_4 : PL: Dieta, Asignación de trabajo Multiperiódico, Asignacion de Trabajo, Procesos de Producción (Deber 3 en python EXP y Gene, Turorial explicando como hacer INDIVIDUAL, Prueba)
- LAB_OR_5 : PL: Inventario, Mezclas, Simplex Dualidad (Proyecto 1. Grupos 3 hacer mezclas en la vida real y obtener el problema dual, Prueba)
- LAB_OR_6 : PL: Transporte, MultiProducto, Asignación (Deber reporte ejercicios Python muchos, desbalanceado)
- LAB_OR_7 : PL: Transbordo (Proyecto 2: Hagan un ejemplo de transbordo en video)
- LAB_OR_8 : Redes: Ruta Corta (Excel y Python), Algoritmo de Dijkstra. Flujo Máximo (Excel, Python) Algorítmo de Iteraciones (Deber individual: Hagan un video tutorial de como usar el algoritmos)
- LAB_OR_9 : Redes: Arbol de expandión mínima, PERT (Deber individual: Hacer un gannt y un pert en pdf, explicando la ruta critica)
- LAB_OR_10 : PE: Asignación de trabajo Multiperiódico, Ramificación y Acostamiento (Solver), Problema Knapsack. (Proyecto 3. Hacer el problema del napsack en grupos VIDEO)
- LAB_OR_11 : PE: K-N restricciones, Problema de Costos Fijos, (Deber individual con ejercicios)
- LAB_OR_12 : PE: Problema de Opción, Problema de Asignación (Deber individual con ejercicios)
- LAB_OR_13 : TSP (el del vehiculo) Proyecro 4 con presentación en clase.
